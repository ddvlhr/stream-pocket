# 拾流 · Stream Pocket

一个可直接加载的 Chrome Manifest V3 视频下载扩展。原生 JavaScript / HTML / CSS，无构建步骤、无远程代码、无需账号。

## 安装

1. 前往 [Releases 下载最新版](https://github.com/ddvlhr/stream-pocket/releases/latest)，下载 `stream-pocket-版本号.zip` 并解压到固定目录。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后直接包含 **`manifest.json`** 的文件夹。
4. 将「拾流」固定到工具栏。刷新已打开的网页，播放视频后点击扩展图标。

从源码安装时，选择本项目的 **`extension` 文件夹**。更新版本后，在扩展管理页点击重新加载，再刷新被检测网页。

## 已实现

- 监听媒体响应的 MIME 类型与 URL；扫描 video / audio / source、媒体链接和 Performance 资源，包括 iframe。
- 按标签页保存发现结果，去重、数量角标、视频尺寸、文件大小、格式筛选和复制完整链接。
- MP4 / WebM / MOV 等直链及音频通过 Chrome 原生下载管理器保存。
- 弹窗内解析 HLS 清晰度，切换后显示对应大小和时长；点击下载即打开独立页面并自动开始所选清晰度的下载。
- HLS 大小优先按平均码率（或标称码率）× 时长估算；没有码率时，最多读取三个分片的 HEAD 响应。估算值标注「约 / 估算」，获取不到时显示「大小未知」，不会把清单大小当作视频大小。最终 MP4 大小可能与源 TS 的估算有少量差异。
- 三个并发分片请求、按原顺序处理、进度与取消。
- 未加密 HLS 点播默认输出 MP4：H.264 / AAC 的 TS 在本地 Worker 中通过 mux.js 无损封装为分片 MP4，不重新编码；也可在弹窗选择保留原始 TS。原生分片 MP4 直接合并。
- HLS / DASH 保存名称优先使用有意义的服务器文件名、播放器标题、VideoObject / OG / 页面标题，避免使用 index / master 等通用清单名；直链文件仍优先保留源文件名。即使底层使用 blob 或嵌入播放器，也会独立读取顶层页面的视频标题。弹窗中可修改，扩展自动添加相应后缀。
- 紧凑弹窗只显示筛选和下载操作，名称仅保留可编辑输入框。扩展品牌、版本和当前页面信息在「关于」中查看。
- 识别 DASH 并导出 `.mpd`；HLS 也支持导出 `.m3u8`。
- 最小文件大小过滤、下载子目录、保存位置选择、关闭自动发现、域名忽略。
- 中文界面；记录使用 session storage，服务工作线程休眠后仍可读取，浏览器退出后清除。设置保存在本机 local storage。

## 支持边界

当前是可用首版，不是参考扩展的全部功能复刻。

| 类型 | 当前能力 |
| --- | --- |
| HTTP(S) 视频/音频文件 | 原生下载；部分站点可能拒绝请求 |
| 未加密、音画复用的 HLS 点播 | 下载并输出 MP4 或 TS，最多 512 MB / 6,000 分片 |
| DASH | 发现、复制地址、导出清单；不合并音画 |
| 加密 HLS、DRM | 不支持 |
| HLS 直播、独立音轨、字节范围、时间线跳变、多初始化分片 | 不支持，显示原因 |
| blob / MediaSource | blob 本身不可下载；尝试捕获其底层网络媒体清单 |
| 重新编码、独立音轨合并、投屏、云盘和跨设备库 | 未实现 |

HLS 下载页面必须保持打开直到 Chrome 完成保存。MP4 封装不改变视频编码，当前 TS 封装支持 H.264 / AAC，其他编码请选择 TS，播放器兼容性由编码决定。没有实现专门站点解析，不保证 YouTube 或任意特定平台可用。

受登录状态、防盗链、第三方 Cookie 策略和签名过期限制，发现链接不代表一定可下载。请求使用浏览器可用的 Cookie，不伪造来源请求头。相对分片地址依据清单最终响应 URL 解析，遵守 URL 标准，不自行复制主清单查询参数。

导出清单只保存索引文件，不等于保存视频；清单中的相对路径或临时签名可能需要其他工具进一步处理。

直链文件大小来自响应头。未知大小及流媒体清单不会被最小大小设置过滤，避免用清单大小误过滤实际视频。每个页面最多保留 150 条媒体地址。

## 隐私

无遥测、无后台服务、无上传。只在本机保留媒体地址与页面标题；链接可能包含临时令牌，请不要把真实记录公开分享。仅下载你有权保存的内容。

## 验证

已打包的 `extension/vendor/` 随扩展直接加载。安装 Node.js 24 或更高版本后可运行测试：

```powershell
npm test
npm run check
```

更新第三方库时执行 `npm ci` 和 `npm run vendor`，将本地 mux.js 文件和 Apache-2.0 许可证同步到 `extension/vendor/`。扩展运行时不加载远程脚本。

测试覆盖清单解析、媒体分类、文件名安全、加密等不支持场景，以及使用模拟 Chrome API 的发现→存储→下载→页面清理流程。静态检查验证 manifest、脚本语法和页面文件引用。

实际浏览器验收：

1. 打开你可控制的带 MP4 视频的网页，播放，确认角标、大小、下载及复制链接。
2. 反复播放或拖动进度，确认同一地址不会重复列出。
3. 打开未加密的 HLS 点播，在弹窗选择清晰度、核对大小、修改名称。点击下载后应直接打开独立页面开始，验证默认 MP4、TS、取消和重试，使用播放器验证输出音画。
4. 验证切换/关闭标签页清理；关闭自动发现或忽略域名后不再新增。
5. 加密和直播流应显示不支持，DASH 仅显示清单导出。

当前环境的自动化验证不替代 Chrome 加载和真实站点下载验收。

## 结构

`extension/background.js` 管理请求发现、会话和原生下载；`content.js` 扫描 DOM；`core.js` 提供解析与数据处理；`popup.*` 提供操作面板；`stream.*` 在独立扩展页面内下载和合并 HLS。

下一步可接入本地 FFmpeg / Native Messaging 以支持大文件、更多编码、DASH 音画合并和转码，再按需要实现直播录制和站点适配。
